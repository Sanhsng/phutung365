# ANTIGRAVITY IDE - PROJECT RULES (GEMINI 3.8 FLASH OPTIMIZED)
1. **NO PLACEHOLDERS:** Tuyệt đối KHÔNG viết `// TODO`, `// ... rest of code`, hoặc bỏ lửng hàm. Mọi file tạo ra phải hoàn chỉnh 100% và chạy được ngay.
2. **TECH STACK:** Next.js (App Router), TypeScript, Tailwind CSS, Lucide Icons, `xlsx` (SheetJS).
3. **SENIOR UI/UX RULES:**
   - Phong cách: Modern Industrial SaaS (nền `bg-slate-50`, card `bg-white border border-slate-200/80 shadow-sm rounded-xl`, màu nhấn `amber-500` và `slate-900`).
   - Mọi Mã phụ tùng (`partNumber`, `crossRefNumbers`, `misaRawCode`) và Số lượng tồn kho BẮT BUỘC dùng class `font-mono tracking-tight`.
   - Giao diện phải có micro-interactions mượt (`transition-all duration-200`), trạng thái hover tinh tế, và hoàn toàn Responsive trên Mobile.
4. **LANGUAGE:** Giao diện người dùng 100% tiếng Việt chuẩn thuật ngữ ngành máy công trình / cơ giới.
